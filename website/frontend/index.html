Research Overview

PROBLEM STATEMENT

Explainability in Network Intrusion Detection

Traditional machine learning based intrusion detection systems can identify malicious traffic, but their predictions are often difficult to interpret. This research integrates Explainable Artificial Intelligence techniques with network intrusion detection to provide transparent explanations for model decisions.

DATASET

UNSW-NB15

The system uses the UNSW-NB15 network intrusion detection dataset containing network traffic records and attack categories.

SHAP

SHAP values quantify the contribution of individual features to a machine learning prediction. The system provides both global feature importance and local explanations for individual traffic records.
